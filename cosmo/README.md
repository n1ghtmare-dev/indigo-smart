# Топливный космоконтур 2035

Локальное решение кейса: расчёт снабжения 2035–2040, сравнение 24 планов, обязательный стресс и реакция, шесть дополнительных рисков, чувствительность, сохранение и интерфейс оператора. Версия ядра 1.0.0. Исходные CSV организатора сохранены без изменений.

Начать с [простого HTML-оглавления](docs/index.html), [результатов](results/project/report.html) или [инструкции оператора](docs/operator.html). Комплект сдачи — в [материалах проекта](docs/delivery.html).

## Запуск интерфейса

Нужен Python 3.11+. Расчёт и интерфейс используют только стандартную библиотеку: без ключей, подписок и установки пакетов.

```sh
python3 scripts/serve.py
```

Откройте http://127.0.0.1:8765 в браузере. Остановка — Ctrl+C. Другой порт: `python3 scripts/serve.py --port 8766`. Сервер слушает только этот компьютер; публичный хостинг и авторизация не реализованы. Не выставляйте сервер в интернет.

На macOS также можно открыть `start.command` двойным щелчком; он запускает ту же команду из папки проекта.

В интерфейсе: готовый план → «Рассчитать план» → сравнить его BASE и стресс → при необходимости «Добавить реакцию B/E». JSON не нужен для обычной работы: отдельные страницы спроса, поставщиков, контрактов, поставок и инвестиций собраны под пунктом «Данные». «Шаблон автопостроения» создаёт только начальный график; затем источники A–E можно сочетать вручную или через матрицу «Годовой план поставок». Перестроение заменяет график после подтверждения, а пересчёт сохраняет текущие контракты и партии. Черновик и ограниченная история запусков с полными снимками входов сохраняются в браузере; повторный запуск не затирает предыдущую запись. Для переноса используйте «Скачать» / «Открыть». Расширенный JSON и пример «2041 + источник X» находятся в разделе инвестиций.

Даты вводятся календарными полями, но календарь модели содержит 365 дней без 29 февраля. Точные дробные даты сохраняются до ручного изменения. Ошибки полей показаны рядом с вводом; полная проверка взаимосвязанных ограничений выполняется при расчёте. Постоянная строка состояния перечисляет изменённые разделы и после расчёта подтверждает, что изменения учтены. Сроки A, B и E защищены в контрольном наборе; свободное исследование сроков доступно только в явно помеченной исследовательской копии.

## Воспроизвести всё

```sh
python3 scripts/verify_preparation.py --write-report
python3 scripts/run_example.py
python3 scripts/run_project.py
python3 scripts/render_docs.py
python3 scripts/build_release_docs.py
python3 scripts/verify_docs.py
python3 -m unittest discover -s tests -v
node --test tests/test_forms.cjs
python3 scripts/verify_project.py
```

Тесты временно открывают локальный порт. В ограниченной песочнице нужен доступ к localhost. Скрипты обновляют генерируемые результаты, не исходные таблицы. Повторить сохранённый запуск:

```sh
python3 scripts/run_case.py --package results/project/selected-stress-adapted/input-package.json --output results/replayed
```

Успешный аудит означает согласованность журналов, а не допустимость плана. Смотрите `status`: FEASIBLE, INFEASIBLE, TARGETS_MISSED, INVALID_PLAN. Валидные планы рассчитываются до конца; объём поставки сверх свободной ёмкости фиксируется как `rejected_t` и нарушение `STORAGE_OVERFLOW`, не попадая в доступный запас.

## Главный результат

Ценовой скрининг 24 вариантов выбирает EARTH_NEW_BASE_R45, но к управленческому разрешению предлагается усиленный EARTH_NEW_BASE_R60_E_INSURANCE: Земля + C, ZBO, R60, заранее оплаченные резервы B и E. Премия защиты к R45 в BASE — 116,488 млн: 32,488 млн за R60 и 84 млн за E. Усиленный пакет проходит BASE, обязательный стресс после реакции, задержку A на 90 дней и спрос +25% после заданных реакций с нулевым дефицитом.

Усиленный BASE: затраты 10 727,15 млн, PV 7 500,01 млн, CAPEX 540 млн, дефицит 0 т. Неизменный пакет в стрессе теряет 144 т обслуживания. После дополнительных заказов: затраты 12 844,14 млн, PV 8 828,94 млн, дефицит 0 т. Цены реальные, база 2035; ставка 10% — допущение команды.

Статус рекомендации — **CONDITIONAL**. При подтверждённых предстартовом B и регулярной доставке C не более 4 месяцев разрешается усиленный пакет. При C=6 месяцев R45 не разрешается: нужен пересчёт и иной пакет. Без подтверждения B в 2034 нужен отдельный стартовый план. Форма и ядро принимают для регулярной доставки C только 2–6 месяцев; нулевой срок отклоняется. Дополнительные риски рассчитаны отдельно и не объединены в универсальную гарантию.

## Структура проекта

- `data/original`, `data/reference`, `data/source-manifest.json`: источники и контрольные хеши.
- `configs/plans`, `configs/scenarios`, `configs/implementation-policy.json`: планы, среды и соглашения.
- `src/cosmo`: календарь, физика, экономика, независимая сверка, планировщик и экспорт.
- `results/project`: сравнения, риски, пакеты и журналы CSV/JSON/HTML.
- `app`, `scripts/serve.py`: приложение; ручные результаты — в `results/operator` с уникальными именами.
- `docs`: простая HTML-документация; ранние заметки также сохранены в Markdown.
- `output`: материалы сдачи. Их пересборка требует библиотек авторинга PDF/PPTX; для ядра они не нужны.
- `tests`: контрольные, граничные, мутационные, интеграционные, HTTP- и headless-браузерные тесты (Chrome; при отсутствии браузера набор корректно пропускается).

Нет публичного хостинга, отправки жюри и самооценки «100/100». [Карта критериев](docs/acceptance.html) показывает доказательства; баллы выставляет жюри. Исходный XLSX не предоставлен. Обновлённый интерфейс проверен в браузере: BASE/стресс/реакция, ошибка спроса у поля, исследовательская копия, построение нового плана и восстановление черновика. Проверена широкая и узкая компоновка. API, маршруты, экспорт и численные сценарии проверяются автоматически. Node.js нужен только для дополнительных тестов преобразований формы, не для работы приложения.

# Источники и происхождение

## Контрольный набор

Три PDF пользователя скопированы без изменения в [data/original/pdf](../data/original/pdf/): постановка, критерии, дополнительные материалы. Исходные имена, URL скачанных файлов и SHA-256 записаны в [source-manifest.json](../data/source-manifest.json).

18 файлов [репозитория организаторов](https://github.com/SpaceEconomyPolicy/test_oil/tree/cec6de1950276091689e71a67f9a875fb4ca6213) зафиксированы на коммите `cec6de1950276091689e71a67f9a875fb4ca6213`: пять CSV, три README, шесть документов правил/методологии, два YAML-сценария и два файла контрольных примеров. Скачаны 18 сентября 2026. В `data/reference/` находятся точные рабочие копии пяти CSV.

Основные таблицы вручную сопоставлены с текстом постановки: спрос по шести годам, мощности/цены/резервирование/TOP/сроки пяти каналов, режимы хранения, инвестиции и ограничения. Контрольные значения отдельно записаны в проверяющем скрипте. Это защита от регрессий и опечаток после сверки, а не независимая экспертиза исходных данных.

Единицы и определения полей: сохранённый [DATA_DICTIONARY.md](../data/original/organizer/docs/DATA_DICTIONARY.md). Расчётные трактовки: [CALCULATION_RULES.md](../data/original/organizer/docs/CALCULATION_RULES.md). Разделение фактов/решений: [CASE_RULES.md](../data/original/organizer/docs/CASE_RULES.md). Сценарии: [STRESS_PROTOCOL.md](../data/original/organizer/docs/STRESS_PROTOCOL.md).

## Ограничения проверки

- Первичный XLSX не предоставлен; README организаторов также отмечает его отсутствие. Сверка с ним не выполнена.
- Ссылка на `ERRATA_AND_PROVENANCE.md` не разрешается внутри сохранённого коммита. Её содержимое нам неизвестно.
- Хеш подтверждает неизменность сохранённого файла относительно манифеста, не истинность фактов и не электронную подпись автора.
- Шесть методических источников проверены на официальных страницах/в полных открытых текстах либо аннотациях. [Карта применения](scientific-basis.html) указывает метод, реализацию и границу прочитанного; недоступный полный текст не выдан за изученный.
- JSON BASE/STRESS — наше представление контрольных сценариев; все изменения в нём проверяются отдельными утверждениями скрипта.
- LOW/HIGH содержат исходный общий спрос; критический спрос вычисляется пропорционально по правилу кейса и FAQ (CASE_INPUT_DERIVED).

При противоречии источников не «усредняем» значения: записываем вопрос, сохраняем обе версии и выбираем трактовку явно. См. [открытые вопросы](open-questions.md).

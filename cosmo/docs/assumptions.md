# Наши решения и допущения

Версия 1.0. Это не дополнительные факты организаторов (кроме явно помеченных правил). Машиночитаемая часть — [model.json](../configs/model.json) и [TEAM_POLICY_V1](../configs/implementation-policy.json). При смене соглашения повторяем сравнение.

| ID | Тип | Значение / единица | Причина и область действия |
|---|---|---|---|
| D01 | Решение | Физический резерв на начало года | Первый вариант; договорный Emergency-эквивалент требует отдельного доказательства |
| D02 | Решение | Критический спрос первым в каждом интервале | Прозрачная политика без оптимизации будущего дефицита |
| A01 | Допущение | 365 дней/год, 365/12 дней/месяц, 7 дней/неделя | Совместимо с контрольной формулой резерва; не григорианский календарь |
| A02 | Допущение | События + расход с интервалом ≤1 дня | Внутригодовой контроль; спрос и выделенная выдача равномерны на интервале |
| A03 | Допущение | Верхняя граница диапазона срока | Трактовки C/D условно определены Q02/Q04 в TEAM_POLICY_V1 |
| A04 | Допущение | Годовая мощность без скрытого месячного лимита | Партии задаются явно; проверяется совокупный годовой объём |
| A05 | Допущение | Резерв проверяется до событий нового года | Нельзя задним числом создать начальный запас поставкой в новом году |
| A06 | Допущение | Потери входящего потока до проверки ёмкости | Согласованное представление потерь на throughput; не испарение от остатка |
| A07 | Допущение | Необслуженный спрос теряется, очереди нет | Иначе пришлось бы изобретать допустимые сроки переноса |
| A08 | Допущение | Нулевой знаменатель KPI → null | Не выдаём отсутствие спроса/потока за доказанное выполнение |
| A09 | Допущение | Любой плановый отбор E в BASE считается базовым | Более строгая проверка серии; аварийные меры в стрессе описываются отдельно |
| A10 | Допущение | Хранение по интегралу линейного запаса | Трапеции точны для выбранной схемы выдачи, не для любой физической модели |
| A11 | Допущение | CAPEX по датам, OPEX/закупки/резерв/хранение в конце года | До появления более подробного платёжного графика; сравнение на одной базе |
| A12 | Допущение | 10% реальных годовых | Чувствительность 0/5/10/15%; не рыночный прогноз |
| A13 | Допущение | Конечный запас показываем без выручки от продажи | Спрос 2041 изучен только в отдельной исследовательской копии |
| A14 | Правило кейса (исправленная классификация) | Для LOW/HIGH сохраняем базовую долю критического спроса | Прямо предписано кейсом и FAQ; вычисленные значения имеют метку CASE_INPUT_DERIVED |
| A15 | Допущение | Decimal 28; допуски 1e-9 т/млн и 1e-12 доли | Защита только от численной погрешности |

Подготовительные расходы оплачены, в денежной сводке относятся к 2035, для PV сохраняется настоящая дата. Q01–Q05 закрыты [условными решениями](open-questions.md), не утверждёнными организатором. Штраф за миссию, выручку и распределения случайных задержек не придумываем. Демонстрация 2041 использует отдельную исследовательскую копию с синтетическими входами, не входящую в BASE.

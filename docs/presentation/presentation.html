О проекте

Что такое IndigoSmart?

Веб-приложение для централизованного мониторинга умного дома. Собирает данные с датчиков (температура, движение), отслеживает состояния устройств (вкл/выкл, яркость), ведёт историю изменений и предоставляет аналитические дашборды.

Мониторинг

Реальное время

Дашборд автоматически обновляется каждые 10 секунд. Видно сколько устройств активно прямо сейчас.

Аналитика

Исторические данные

Температура по дням (мин/ср/макс), активность по часам, динамика обнаружения движения.

Управление

Контроль устройств

Список устройств по комнатам с возможностью изменения состояния через REST API.

База данных

Схема MySQL

Шесть нормализованных таблиц. Текущая статистика: 630 событий состояний, 2160 показаний датчиков.

rooms 3 записи
  • idint
  • namevarchar(100)
  • descriptionvarchar(255)
  • created_attimestamp
device_types 7 записей
  • idint
  • name UNIQUEvarchar(100)
  • is_sensorbool
devices 9 записей
  • idint
  • namevarchar(100)
  • room_id →FK rooms
  • device_type_id →FK types
device_states 630 записей
  • idint
  • device_id →FK devices
  • state_typeON/OFF, brightness
  • state_valuevarchar(50)
  • changed_attimestamp
  • changed_by →FK users
sensor_readings 2160 записей
  • idint
  • device_id →FK devices
  • reading_typetemperature, motion
  • valuefloat
  • recorded_attimestamp
users 2 записи
  • idint
  • full_namevarchar(100)
  • email UNIQUEvarchar(150)
  • password_hashvarchar(255)
REST API

Эндпоинты FastAPI

Четыре роутера: dashboard, devices, sensors, analytics. Авто-документация на /docs.

GET/dashboardсводная статистика для главной
GET/roomsсписок комнат с числом устройств
GET/devices?room_id=...устройства с последним состоянием
GET/devices/{id}устройство + история (20 событий, 50 показаний)
PUT/devices/{id}/stateзаписать новое состояние
GET/analytics/summaryагрегированная сводка
GET/analytics/temperature/dailymin / avg / max по дням
GET/analytics/motionобнаружения движения по дням
GET/analytics/activity/hourlyраспределение событий по часам (0–23)
GET/analytics/device-typesколичество устройств каждого типа
Frontend

Страницы админки

/admin/default

🏠 Главная

6 виджетов KPI (комнаты, устройства, активные, сенсоры, события, ср. температура). График температуры, недельная активность, статус всех устройств, диаграмма типов, события движения.

↳ TemperatureChart · WeeklyActivity · PieChartCard · MotionEvents · DeviceStatusCard

/admin/devices

📱 Устройства

Таблица всех устройств с фильтрацией по комнатам. Отображение типа, статуса (вкл/выкл) и принадлежности. Построено на @tanstack/react-table.

/admin/analytics

📊 Аналитика

Расширенная аналитика: 4 KPI + Area-график температуры (мин/ср/макс), Bar-график движения за 14 дней, активность по 24 часам.

↳ LineChart · BarChart · ApexCharts

🎨 Общие элементы UI

Navbar (верх) · Sidebar с навигацией · Widget (карточка KPI) · Card (обёртка с тенью) · MiniCalendar. Тема: dark/light переключаемая.

UI в действии

Главный дашборд

📈 Данные сейчас

3 комнаты, 9 устройств, 5 сенсоров. Средняя температура 21.2°C. Всего за всё время — 630 событий.

🔄 Авто-обновление

setInterval(fetchData, 10000) — данные подтягиваются каждые 10 секунд без перезагрузки страницы.

🌗 Темная тема

Tailwind dark:-классы. Все графики используют тёмные оси и градиентные заливки.

Запуск

Как развернуть локально

1. База данных

# Импортируем дамп в MySQL mysql -uroot < smart_home_db.sql # Либо чистая инициализация + seed mysql -uroot < smart-app/init_db.sql python smart-app/seed_all.py

2. Backend

cd smart-app pip install fastapi uvicorn sqlalchemy \ pymysql cryptography python-dotenv uvicorn main:app --app-dir src/smart_app \ --host 127.0.0.1 --port 8000

3. Frontend

cd smart-board npm install npm start # Откроется http://localhost:3000

4. Проверить

# API docs http://127.0.0.1:8000/docs # Дашборд http://localhost:3000/admin/default # Аналитика http://localhost:3000/admin/analytics

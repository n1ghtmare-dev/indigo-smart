Рисунок 3 ER-диаграмма базы данных IndigoSmart

rooms 3 записи
  • PK idINT
  • nameVARCHAR(100)
  • descriptionVARCHAR(255)
  • created_atTIMESTAMP
device_types 7 записей
  • PK idINT
  • name UNIQUEVARCHAR(100)
  • is_sensorBOOL
  • created_atTIMESTAMP
devices 9 записей
  • PK idINT
  • nameVARCHAR(100)
  • FK room_id→ rooms
  • FK device_type_id→ types
device_states 630 записей
  • PK idINT
  • FK device_id→ devices
  • state_typeVARCHAR(50)
  • state_valueVARCHAR(50)
  • changed_atTIMESTAMP
  • FK changed_by→ users
sensor_readings 2160 записей
  • PK idINT
  • FK device_id→ devices
  • reading_typeVARCHAR(50)
  • valueFLOAT
  • recorded_atTIMESTAMP
users 2 записи
  • PK idINT
  • full_nameVARCHAR(100)
  • email UNIQUEVARCHAR(150)
  • password_hashVARCHAR(255)
Связи между таблицами:
rooms→devices  1:N device_types→devices  1:N devices→device_states  1:N
devices→sensor_readings  1:N users→device_states  1:N

Внешние ключи на devices определены с правилом ON DELETE CASCADE; связь users → device_states — с правилом ON DELETE SET NULL.

Рисунок 4 Структура серверной части IndigoSmart

smart-app/ ├── src/smart_app/ │ ├── main.py# инициализация FastAPI, CORS │ ├── config.py# Settings, чтение .env │ ├── db.py# engine, SessionLocal, get_db │ ├── models.py# 6 ORM-моделей │ └── routes/ │ ├── dashboard.py# /dashboard │ ├── devices.py# /devices, /rooms │ ├── sensors.py# /sensor-readings │ └── analytics.py# /analytics/* ├── pyproject.toml# зависимости ├── init_db.sql# DDL схема ├── seed_all.py# генератор тестовых данных └── .env# параметры MySQL
main.py · точка входа

Создание объекта FastAPI, подключение CORS middleware для домена клиента, вызов create_all для схемы БД, регистрация всех роутеров.

models.py · ORM-модели

Room, DeviceType, Device, DeviceState, SensorReading, User. Связи через relationship с каскадом удаления.

db.py + config.py · подключение

Settings читает параметры MySQL из .env, engine SQLAlchemy и SessionLocal. Функция get_db — генератор сессии для зависимостей FastAPI.

routes/ · бизнес-логика

4 роутера по предметным областям, 10 эндпоинтов, агрегация через GROUP BY DATE/HOUR в SQLAlchemy.
